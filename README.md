# 家伴到 Family Errand

## 项目目标

为在外工作、生活的年轻人提供一个下单平台，让本地接单人代为采购并配送生活补给品给家中老人。订单需记录家属信息、采购明细，以及采购和配送履约过程中的凭证。

## 订单流程

买家创建订单（家属姓名、家庭住址、联系电话、商品名称/数量/单位及备注） → 接单人接单 → 采购后上传票据照片和票据明细 → 填写导航距离并可附路线截图，开始送货 → 确认送达并记录送达备注 → 结束订单。

## 当前版本

`index.html` 是无需安装依赖、可直接在浏览器打开的交互式前端原型。支持创建订单、多商品明细、接单、上传票据记录、导航距离/路线凭证、送达确认、结束订单和订单状态筛选。订单数据保存在浏览器本地。

当前上传控件仅记录文件名，附件不会传到服务器。原型尚未接入账号体系、真实文件存储、支付结算、地图导航、消息通知或后端数据库；不可用于真实交易。

## 运行

用现代浏览器打开 `index.html` 即可体验。点击“创建采购订单”可创建买家订单；订单卡片上的操作按钮依次推进流程。

## 后续建议

1. 确认买家、接单人和收货家属的角色与权限。
2. 设计后端 API、订单数据库、登录鉴权和订单状态审计日志。
3. 接入对象存储保存票据与导航凭证，并限制访问权限。
4. 接入地图路线/导航距离、订单通知和支付/退款流程。
5. 再评估 AI 功能：商品清单识别与结构化、票据 OCR 对账、智能客服或路线/补货建议；涉及付款和订单状态变更需人工确认。

## 隐私

家庭住址和联系电话属于敏感个人信息。正式上线前应取得必要授权、限制员工访问、保护传输与存储，并设置订单完成后的数据保留期限。
